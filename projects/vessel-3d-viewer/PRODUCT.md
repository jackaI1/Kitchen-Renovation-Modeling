# Vessel inspection viewer

I use this local inspection tool to connect compartment readings to positions inside a simplified hull. The primary task is to locate an abnormal simulated reading and inspect the matching compartment. Desktop orbit view is the default; compatible headsets can enter a tabletop immersive view.

The explicit project brief supplies the scope: four compartments, tank levels and temperatures, simulated WebSocket data, three.js/glTF and Blender/Python import. Assumptions: daylight desktop use, no real vessel control, fixed model manifest, no uploaded files or authenticated service. All values are labelled simulated. Hardware XR verification is an explicit limitation.

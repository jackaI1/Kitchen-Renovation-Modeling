# Inspection surface

Mode: operate. The vessel is the central working object, with a compact reading list alongside it. On phones the list follows the model. Controls describe the metric and simulation scenario directly.

The palette uses a pale blue-grey viewing surface (#e7eff3), off-white page (#f6f9fa), marine text (#18394c), normal blue (#247da0), watch amber (#a26300), alarm red (#ba342e), and stale grey (#737f89). Status names accompany every colour. Type uses the installed Avenir Next family with a sans-serif fallback; values use tabular numerals. Body text is 16 px, main heading 26–34 px, secondary copy 13–14 px.

The signature interaction is switching an alarm scenario and immediately seeing the relevant compartment and its label change. The hull stays translucent so all compartment geometry remains inspectable. Selection works through both the mesh and keyboard-accessible list buttons. Loading, rejected models, WebGL failure, stale data and headset access each have visible text. There is no decorative motion; orbit damping answers user movement.
